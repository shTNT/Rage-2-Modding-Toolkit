1. DECA project
   ---------------------------------------------------------------------------
   Data and format documentation used under research/modding fair use.

   a) resources/deca/rg2/filelist.txt (358,057 entries)
      Raw path database used to reverse MurmurHash3 hashes back to real names.

   b) python/deca/deca/ff_arc_tab.py
      Reference TAB v3.1 parser. Documented the multi-block compression layout
      that RAGE 2 archives use. The multi-block handling in this toolkit's
      extractor is a direct port of the logic found here.

   The DECA project's reverse engineering work is foundational to this toolkit.

2. REDxEYE - ApexPredator
   ---------------------------------------------------------------------------
   Author: REDxEYE
   Source: https://github.com/REDxEYE/APEX-PREDATOR

   a) Hash extractor output (103,428 hash-to-path entries)
      The full filelist shipped with the toolkit (data/filelist.txt) is built
      from REDxEYE's hash extractor. It covers 36,695 of the 39,519 gameplay
      hashes in the 46 .arc archives the toolkit extracts (92.85%), plus
      ~66,733 additional paths from DLCs, other locales, and engine-referenced
      assets not shipped as standalone files in every install.

   b) File format research
      Reference work on the Avalanche Apex engine formats: .atxN mipmap family,
      modelc = adf, sarc.gtoc path handling. Used as cross-reference.

   The toolkit itself is entirely our own work. REDxEYE's extractor gave us
   reach; the parser, writer, GUI and installer are ours.
