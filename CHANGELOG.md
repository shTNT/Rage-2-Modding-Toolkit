# Changelog

## [2.1.5] - 2026-09-30

### World Settings Editor - snapshot tracking + pending changes viewer

**Fixed**
- Snapshot restore no longer leaves stale pending changes for the restored file.
- Grid no longer goes empty after restoring a snapshot.
- Status bar now reflects the real pending state after restore (multi-file aware).
- Footer: removed overlapping CHANGES button. Merged into clickable status bar.

**Added**
- PendingChangesForm - full-screen list of every pending change across all loaded files.
- Click on the status bar (underlined, hand cursor) to open the viewer.
- Custom tree render for Asset Memory Budgets (Categories + 12 Budget Slots).
- 20 new property names resolved for Spawn Budget Pool.
- 2 new property names for Asset Memory Budgets: memory_max (KB), soft_limit (KB).

### VRAM Bomb + Spawn Grenade (mods pack)
- 8 ready-to-install ZIPs for Mod Manager.
- Each ZIP includes enriched mod.json with tier, rationale, patched props count.
- HTML guide (CONFIDENT_README.html) ready to paste into Nexus mod page.
