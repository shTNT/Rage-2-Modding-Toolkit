Part 1 · Installing mods Players

You downloaded a mod — a .zip file from Nexus, ModDB, or a Discord server. Here is how to get it running.

What you need

  • A legitimate copy of RAGE 2 installed (Steam, GOG, Epic, wherever).
  • About 1 GB free on the drive where you keep the toolkit — backups of the game's archives are stored there.
  • Windows 10 or 11 (x64).
No tech skills required

You do not need to know what a .arc file is or where the game keeps its data. The toolkit handles all of that.

· · ·

Step 1 — Get the toolkit

Download the release

Grab RAGE2TOOLKIT-v2.1.0.7z from the GitHub releases page.

Extract it anywhere

Desktop, D:\, a folder in your documents — wherever you keep tools. You will get a folder containing RAGE2Toolkit.exe, a bin\ folder, a data\ folder, and a few text files.

Do not move files around

The toolkit expects that exact layout. If you move bin\ or data\ out of the folder, it will not work.

Step 2 — First launch

Double-click RAGE2Toolkit.exe

Do not launch it from a PowerShell or Command Prompt window. Windows inherits a wrong working directory that way and drag-and-drop stops working.

Point it at your game folder

On first run the toolkit asks where RAGE 2 lives. That is the folder containing Rage2.exe. Common locations:

  • C:\Program Files (x86)\Steam\steamapps\common\RAGE 2
  • C:\Program Files\Epic Games\RAGE2
  • C:\GOG Games\RAGE 2

Let it auto-copy the Oodle runtime

The toolkit needs a DLL (oo2core_7_win64.dll) that lives in your game folder. It copies it automatically on first launch and deletes it again on close. Nothing for you to do.

Step 3 — Install the mod

Open the Mod Manager

From the main menu, click MOD & REPACK, then MOD MANAGER.

Drag the mod's .zip into the window

Or click Install and pick the file.

Let it do its thing

The toolkit reads the mod's metadata, figures out which archive files it touches, backs those up, rewrites them with the new content, and registers the mod. You will see it appear in the list.

First install takes longer

The very first mod you install triggers a full backup of the affected archive. Depending on the mod, that can be anywhere from a few seconds to a minute. Later installs of the same archive are instant.

Step 4 — Play

Launch RAGE 2 the way you normally do. Load a save. The mod should be there.

Backups and recovery

  • On the first install of any mod, the toolkit copies the affected archive files into mods\backups\.
  • Those backups never change unless you explicitly use Restore All.
  • If something breaks the game, open the Mod Manager, click Restore All. Your game folder goes back to the pristine state.
  • Manual restore: the backups are just files. You can copy them back into your game's archives_win64\ folder if you know what you are doing.

Common problems

The mod does not appear in the list after drag & drop

The file you have is not a toolkit mod. Open the .zip — inside it should contain one or more files named with a 16-character hexadecimal code, like FC0BD72039E0B01D.atx1 or 67B4C03CA7428D09.ddsc. If instead you see textures, images, or a documentation file, you probably downloaded a resource pack that requires manual installation.

The game crashes on load after installing

Uninstall the last mod you added. If that fixes it, the mod itself has a problem. Report it to the mod author with the exact .zip name.

"Drift detected" error

Something modified your game's archive files outside of the Mod Manager — an old manual install, another tool, or a cracked patch. Run Restore All to get back to a clean state, then reinstall your mods. Advanced users can use the --force CLI flag to override the check, but you should know exactly why the drift happened first.

Step 1 — Pick what you want to change

Three ways to get the assets you need. Choose the one that fits your mod.

Option A · Single asset browser

For when you know exactly what you want to edit.

  1. From the main menu, click EXTRACT → BROWSE & PICK MANUALLY.
  2. Navigate the tree or search by keyword, path fragment, or hash.
  3. Select your assets. Click Convert & Extract to get editable PNG/DDS, or Extract raw only to get the game's native formats.
  4. Files land in your chosen output folder, organized one folder per entity.

Option B · Full extract

For when you want to browse everything at your leisure, or you are doing multiple mods at once.

  1. From the main menu, click EXTRACT → EXTRACT EVERYTHING.
  2. Takes about 5 minutes on a modern NVMe drive, up to 30 minutes on older hardware. Needs ~60 GB free.
  3. Result: every asset in the game, organised into _EDITABLE\TEXTURES\, _EDITABLE\AUDIO\, _EDITABLE\SCRIPTS\, and so on.

Option C · World Settings Editor

For changing game behaviour: how many enemies spawn, how hard they hit, how much health the player has, how damage types work, weather and lighting.

  1. From the main menu, click MOD & REPACK → WORLD SETTINGS EDITOR.
  2. Pick a file from the dropdown at the top. A short description tells you what it controls.
  3. Click a category in the tree. The properties appear on the right.
  4. Edit the New value column. Modified rows turn magenta.
  5. Click SAVE. The toolkit backs up the original, applies your changes, and builds the .zip for you. Skip straight to Step 4.
Tip

The single most impactful setting in the editor is Spawn Budget Pools → Civilians → Amount in World. Default is 0.5. Set it to 3.0 and load a save in Wellspring. The difference is immediate.

Step 2 — Edit the assets

Open the extracted files in your tool of choice. Save them back to the same extension the toolkit gave you — if a texture came out as .png, save it as .png. The toolkit converts it back to the game's native format when you pack.

Textures — good to know

  • Colour maps (_dif, _emc, _albedo, _color) — keep sRGB encoding when saving.
  • Data maps (_nrm, _mpm, _msk, _dtm) — linear, do not apply sRGB.
  • Keep the original resolution unless you have a reason not to. Larger textures work but eat VRAM fast and can cause stutter.

Audio — good to know

  • OGG Vorbis. 44.1 kHz or 48 kHz. Match the original's channel count — mono for SFX, stereo for music.
  • Bitrate: 192 kbps is a safe default. Higher for music, lower for short effects.

Video — good to know

  • Match the codec (Bink 1 .bik vs Bink 2 .bk2) of the file you are replacing.
  • Keep the original resolution and framerate. The engine does not rescale.
  • RAD Video Tools can open both Bink 1 and Bink 2 files and re-encode them.

Step 3 — Pack the mod

  1. From the main menu, click MOD & REPACK → REPACKER.
  2. Drag the folder containing your edited files onto the wizard. Or click Browse and pick it.
  3. Choose Raw if you already converted everything back to the game's native formats (e.g. saved as .ddsc). Choose Convert if the folder has PNGs, WAVs, or DDS files that the toolkit should convert for you.
  4. Click Next. The wizard scans every file, matches it against the game's file list by hash, and shows a summary.
  5. Click Next again. A dialog asks for a mod Name and Author.
  6. The toolkit builds <slug>.zip in RAGE2Toolkit_Output\mods_export\ and offers to open the folder.
The resulting .zip

Contains a mod.json with the metadata plus one file per edited asset, each named with its 16-character hash. This is what other players need to install your mod.

Step 4 — Test it in your own game

  1. Drag the .zip into your own Mod Manager.
  2. Click Install.
  3. Launch RAGE 2, load a save, verify your change looks right.
  4. If you need to adjust: modify your working folder, repack, reinstall. The Mod Manager overwrites the previous version cleanly.

Step 5 — Share it

Upload the .zip to your preferred modding platform. The main destinations:

PlatformWhy
Nexus ModsBiggest RAGE 2 modding audience. Free hosting up to 500 MB.
ModDBGeneral modding audience, less RAGE 2-specific but broader reach.
Discord · DECAThe #rage-2 channel. Active community, quick feedback.
What to include in your upload

The .zip file itself, a short description of what it changes, and a screenshot if you can. Players who download it just drag it into their Mod Manager and click Install — no manual steps.

Advanced · Making a world-alive mod

The single highest-impact mod you can make with this toolkit. RAGE 2's world feels empty by design — the spawn rates are conservative. You can change that.

Open the World Settings Editor

From the main menu: MOD & REPACK → WORLD SETTINGS EDITOR.

Pick Spawn Budget Pools

It is the first file in the dropdown. Click Civilians in the tree.

Change Amount in World

The default is 0.5. Set it to 3.0.

SAVE, install, load

SAVE builds the .zip. Install it in your Mod Manager. Launch the game and load a save in Wellspring.

Tune from there

Try other categories one at a time: Combatants for more random fights, Drivers for more traffic, Encounters for more dynamic events. One change, test, then next.

Do not go overboard

Very high values can hurt performance or crash the game. Stick to the range 0.1 to 20.0. Increase in small steps and test in-game between changes.
