# v1.3.1 Correction - 2026-09-24

## Problem found

The v1.3.1 filelist contained 106 entries with mismatched hash/path pairs.
The hashes are real (present in the game's .tab files), but the paths
attached to them do NOT hash back to those hashes. Verification:

    hash(path) != entry_hash    (for all 106 entries)

Origin: merge contamination in the brute-force pipeline. Entries survived
all merges because the merge tool dedupes by hash alone, not by verifying
hash+path consistency.

## Impact

- v1.3.1 reported coverage: 91.85% (36,298 hashes).
- Real coverage of v1.3.1: 91.58% (36,192 hashes).
- 106 phantom entries removed.

## Fix

- `data/filelist.txt` now contains 36,192 verified hash/path pairs.
- `hash(path) == entry_hash` for all 36,192 entries.
- No real data was lost: the 106 removed hashes were already orphans
  (unknown real path) in the corrected coverage.
