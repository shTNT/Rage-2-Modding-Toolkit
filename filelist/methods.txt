1. HASH ALGORITHM SPECIFICATION
================================================================================

RAGE 2 identifies assets with 64-bit hashes derived from path strings.

Algorithm:      MurmurHash3 x64 128-bit
Input:          path in UTF-8, lowercase, forward slashes, no prefix
Seed:           0
Output used:    h1 (first 64-bit word of the 128-bit digest)

Verified test vectors:

    text/master_eng.stringlookup                                -> 8453EE3581F31F39
    ai/tiles/43_37.navmeshc                                     -> E73A9076A24B7E8D
    terrain/heatwave/patches/width_8/patch_11_00_00.streampatch -> 95C8093796E2DD75

CRITICAL WARNING: Implementations that use h2 (second 64-bit word), or
that XOR the two halves of the digest, produce 0 matches. Verify with
the test vectors above before assuming your paths are wrong.

2. GAME STRUCTURE AND UNIVERSES
================================================================================

The game ships with TWO complementary archive directories:

    archives_win64/initial/       13 .arc + 13 .tab  (base game, 16,385 hashes)
    archives_win64/supplemental/  33 .arc + 33 .tab  (DLC, 23,134 hashes)

    OVERLAP between universes: 0 hashes
    UNION: 39,519 unique gameplay hashes

There is also a separate localization tree:

    languages/<locale>/game0.tab   3,113 to 37,844 hashes per locale
    Total localization hashes:     45,739

LOCALIZATION IS NOT INCLUDED in this filelist. Reporting coverage that
includes locales inflates the denominator by 2.16x and is misleading
for asset modding purposes.

================================================================================
3. FILELIST FORMAT
================================================================================

Tab-separated format:

    <HEX16>\t<path>

    HEX16 = 16-character uppercase hexadecimal hash
    path  = asset path as understood by the game engine

UTF-8 without BOM, LF line endings.

--- 6.3 VERIFICATION ---

The bit-a-bit verification script re-hashes every path in the final
filelist and checks membership in the .tab files:

    1. For each line "HASH\tPATH":
       - recompute MurmurHash3_x64_128(PATH, seed=0)
       - compare to HASH
    2. Look up HASH in initSet and suppSet
    3. Report OK / mismatch / ghost counts

7. NEGATIVE FINDINGS / WARNINGS
================================================================================

- DECA filelist sometimes has paths prefixed with "|". Strip before hashing.
- .tab file format 3.1: magic 0x00424154 @0x00, file_count @0x0C (NOT 0x1C).
- Aliases: same hash can map to multiple paths. Dedupe by HASH.
- Two universes (initial + supplemental) with 0 overlap.
- Localization (45,739 hashes) excluded. Including it = 2.16x denominator.
- Oodle v7 (oo2core_7_win64.dll) required, NOT redistributable.
- Scaleform CFX magic is "CFX\x1F" (byte 0x1F), NOT "CFX " (space 0x20).
- PowerShell 5.1 cannot compare hex > 0x7FFFFFFFFFFFFFFF. Use .ToString("X16").
- Visual Studio Build Tools only needed for compiling native C++ hooks.

- CEILING REACHED: The remaining 2,824 orphans are NOT reachable via
  static analysis. Verified empirically by ~55 billion candidate
  tests across 15+ tools (2026-09-26 final sweep).

- The only remaining path would be a runtime hook (MinHook on
  Murmur3Hash), which was evaluated and discarded: requires playing
  the entire game (multiple sessions across all biomes/DLCs) and
  produces ~900 MB logs per 3 min of gameplay.
