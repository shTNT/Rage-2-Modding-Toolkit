# v2.0.2 - Repacker .tab hotfix

Fixes the two format-level bugs in the repack writer that silently hung the
game on load. Both were invisible from SHA comparison and only surfaced
during an in-game test with a replaced weapon texture.

## Fixed

### Block table sentinel
The writer was emitting a block table without the terminating
`FFFFFFFF FFFFFFFF` entry. The engine computes the file table offset as
`0x20 + block_count * 8`; without the sentinel, `block_count` was one
short and the engine read the first file entry as if it were part of the
block table. Result: silent hang on load.

### File table sorted by hash
The engine performs a binary search on the file table by hash. The writer
was emitting entries in physical-offset order. Binary search returned wrong
results; the game hung looking for the archive index. Writer now sorts
entries with `OrderBy(e => e.Hash)` before serializing.

## Validation

- Round-trip with zero changes: `.tab` byte-identical to original
  (SHA256 match against the reference baseline).
- Replacement test: single `.atx1` texture swap on `game8.arc`,
  in-game load confirmed, replaced texture visible.
- Baseline: all 46 original `.arc` untouched after every operation.

## Notes

- Only textures tested. Audio, video, UI, scripts, meshes not yet validated.
- Only RAGE 2 tested. Generation Zero has the same TAB 3.1 struct per
  REDxEYE but uses lookup3 32-bit for hashing.
- See `src/REPACKER_NOTES.md` for the full format spec and porting notes.
